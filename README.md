# SIGIL – Laboratorio Forense de Cadenas

Laboratorio criptográfico en tiempo real ejecutado enteramente en el navegador.

- **Disección y Autopsia de hashes** (MD5, SHA-1, SHA-256, SHA-512)
- **Entropía de Shannon**
- **Inspección de memoria byte por byte**
- **Generación de sellos SVG generativos**
- **Tecnologías:** React 19, Tailwind CSS 4, Framer Motion, Web Crypto API.

Desplegado 24/7 con GitHub Pages.
